# Pilihan penyedia API

BinderByte dipilih untuk versi awal karena dokumentasinya menyediakan satu endpoint GET sederhana untuk nomor resi dan menyebut dukungan 28 ekspedisi, termasuk JNE, J&T, SiCepat, POS, AnterAja, TIKI, Shopee Express, dan Kurir Tokopedia.

Dokumentasi:
- https://binderbyte.com/docs/resi
- https://docs.binderbyte.com/

Periksa dashboard untuk paket, kuota, dan harga terbaru sebelum mengaktifkan tracking otomatis.
